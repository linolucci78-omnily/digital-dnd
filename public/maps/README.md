# 🗺️ Maps Directory

This folder contains battle maps for the Lost Mine of Phandelver adventure.

## Quick Links to Free Maps

### 🎁 Complete Map Packs (Download All at Once!)

**Best Option - Reddit Community Packs:**
1. Search Reddit: https://www.reddit.com/r/LostMinesOfPhandelver/
2. Look for posts titled: "Complete Map Pack" or "All Maps"
3. Users often share Google Drive/Dropbox links with ALL maps!

**Popular Packs:**
- Mike Schley's Player Maps (some free): https://mikeschley.com/
- 2-Minute Tabletop: https://2minutetabletop.com/gallery/
- Forgotten Adventures: https://www.forgotten-adventures.net/

### 📍 Individual Map Sources

#### r/battlemaps (Free Community Maps)
https://www.reddit.com/r/battlemaps/

Search terms:
- "Cragmaw Hideout"
- "Redbrand Hideout"

## 💾 How to Add Maps

1. Download map image (JPG or PNG)
2. Rename to match the filename above (exact match!)
3. Place in this `/public/maps/` folder
4. Test: Open `http://localhost:5173/maps/FILENAME.jpg` in browser

---

## ✅ Recommended Specifications

- **Format:** JPG (smaller) or PNG (higher quality)
- **Resolution:** 1920x1080 minimum, 2560x1440 ideal
- **File Size:** < 5MB per map (for performance)
- **Aspect Ratio:** 16:9 or 1:1 (square)
